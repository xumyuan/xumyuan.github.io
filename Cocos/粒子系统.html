粒子系统 ​

CPU粒子 ​

cocos的cpu粒子整理的流程比较直观，初始化配置好粒子信息后，在每帧的处理中，对启用了的模块机型相关处理，然后把计算完的粒子状态和属性上传到gpu进行渲染

CPU粒子的主要流程大致如下：

初始化 ​

CPU端的粒子系统初始化信息如下：

typescript
// cocos/particle/renderer/particle-system-renderer-cpu.ts:217
    public onInit (ps: ParticleSystem): void {
        super.onInit(ps);

        this._particles = new RecyclePool((): Particle => new Particle(this), 16);
        this._setVertexAttrib();
        this._setFillFunc();
        this._initModuleList();
        this._initModel();
        this.updateMaterialParams();
        this.updateTrailMaterial();
        this.setVertexAttributes();
        this._inited = true;
    }

初始化主要做了这么几件事：

保存组件引用，准备粒子对象池 ​

将传入的ps保存到基类的this._particleSystem，capacity和材质信息等都是从这里读取 new RecyclePool：创建了一个粒子池，用来复用粒子数据。池子的大小由ps.capacity控制，初始化默认创建16个

选取数据布局、写入函数和模块布局 ​

  1. _setVertexAttrib：设置了顶点的属性布局
  2. _setFillFunc：决定数据怎么写，比如要写入粒子的哪些属性
选中的函数具体怎么写
_fillNormalData普通 Billboard。非实例化时给四个角点各写一份粒子状态，每个角点有自己的 UV。实例化时每颗只写一份，四个角点的 UV 来自共享的 Quad。
_fillStrecthedData在普通 Billboard 的数据上额外写入 p.ultimateVelocity。顶点 Shader 用这个速度确定拉伸方向和长度。
_fillMeshData写粒子自身的状态，供 Shader 缩放、旋转和摆放 Mesh。Mesh 原有的顶点位置、UV 等由批模型准备。
  1. _initModuleList：决定哪些粒子要哪些模块，模块的的执行顺序也是固定的

创建批模型，配置材质并构建缓冲 ​

  1. _initModel：创建粒子的数据模型
  2. updateMaterialParams：处理粒子的材质槽0，同时会设置渲染模式、实例化、世界空间等shader宏
  3. updateTrailMaterial：在开启了拖尾时，配置材质槽1，选择拖尾材质并设置空间坐标宏
  4. setVertexAttributes：把之前选好的 _vertAttrs 和可选的 Mesh 交给 ParticleBatchModel，由它计算属性偏移和步长，构建顶点、索引或实例缓冲。

粒子发射 ​

无论cpu还是gpu粒子，粒子的发射都是由cpu控制，整体的逻辑链如下：

text
ParticleSystem.update(dt)
    → _emit(dt)
        → emit(count, dt)
             ├─ processor.getFreeParticle()
             ├─ ShapeModule.emit(p)
             ├─ 初始化速度、大小、旋转、颜色
             ├─ 初始化寿命、随机种子
             └─ processor.setNewParticle(p)

这里getFreeParticle会检查粒子池的容量是否足够，足够的情况会返回对象池的对象并增加活跃计数，gpu粒子没有维护粒子池，所以粒子的增加逻辑不在这里（在setNewParticle）

每帧模拟 ​

核心处理逻辑在updateParticles，在做完重力和拖尾模块的处理之后，会对八个生命周期模块按照固定的顺序写状态

在updateParticles之前，开启 renderCulling 时，系统用估算的 AABB 做视锥测试。将屏幕外的粒子剔除

顺序模块实际作用
1Sizesize = startSize × 曲线值，支持统一缩放或分别控制 XYZ
2Colorcolor = startColor × 渐变色，逐帧从初始颜色重新计算
3Force把曲线当作加速度，执行 velocity += force × dt，并同步 ultimateVelocity
4Velocity将曲线速度加到本帧的 animatedVelocity，算出 ultimateVelocity = (velocity + animatedVelocity) × speedModifier
5Limit Velocity对合成后的速度按模长或分轴做超限衰减，结果同时写入 ultimateVelocity 和 velocity，会延续到下一帧
6Rotation对曲线角速度乘 dt，累积增量旋转，再与初始旋转合成
7Texture Animation按年龄和 cycleCount 算归一化的 frameIndex，支持整张图或指定行、随机行
8Noise根据当前位置和系统时间采样噪声，把偏移乘 dt 直接加到 position

打包粒子状态，上传到gpu绘制 ​

ParticleSystem.beforeRender() 处理 model 的挂载状态，播放中调用 processor.updateRenderData() 和 processor.beforeRender()。前者遍历活粒子，将模拟字段打包成 PVData，后者把数据交给 ParticleBatchModel.updateIA()。这里的 IA 是 Input Assembler，记录绘制使用的顶点缓冲、索引缓冲和绘制数量。 以 Billboard 为例，两种布局的区别在于每颗粒子写几次、图集帧放在哪里：

数据非实例化实例化
粒子中心a_position.xyz，每个角点重复写a_texCoord4.xyz，每实例写一次
图集帧a_texCoord.za_texCoord4.w
Quad 角点a_texCoord.xy，每颗写四个角点静态流里的 a_texCoord.xy，所有实例共享
尺寸、旋转、颜色a_texCoord1、a_texCoord2、a_color同名属性，按实例读取
拉伸速度a_color1.xyz，来源是 ultimateVelocity同名属性，按实例读取

顶点shader把粒子状态变成几何 ​

cpu粒子这一步主要就是处理粒子的渲染几何，比如Billboard的实现，还有就是mesh的一些朝向问题。 以最常见的普通 Billboard 为例，这一步的主体就是 把四个角摆到粒子中心周围，让四边形面向相机，然后做 VP 投影。

text
CPU 给出粒子中心、尺寸和旋转
    ↓
顶点 Shader 取当前角点的偏移，例如左下角 (-0.5, -0.5)
    ↓
按尺寸和旋转调整偏移，再沿相机的右、上方向摆到中心周围
    ↓
得到该角点的世界坐标，乘 cc_matViewProj

片元计算 ​

片元计算就是正常的将粒子渲染到屏幕上

GPU粒子 ​

目前cocos的GPU粒子主要由CPU将生命周期属性的曲线、渐变配置采样并打包为纹理，供顶点着色器结合出生数据和年龄计算当前运动与外观，而非采用 Compute Shader 逐帧更新粒子状态。

GPU粒子的流程大致如下：

初始化 ​

在启用了useGPU之后并且通过设备检测之后：

ParticleSystem.onLoad()
    → renderer.onInit(ps)
        → new ParticleSystemRendererGPU(...)  //这里之前的逻辑是cpu和gpu共用的
        → GPU processor.onInit(ps)
             ├─ _setVertexAttrib()
             ├─ _initModel()
             ├─ updateMaterialParams()
             └─ setVertexAttributes()

这里初始化主要做了这么几件事：

  1. _setVertexAttrib：确定了属性布局
  2. _initModel：创建模型
  3. updateMaterialParams：获取或创建gpu材质、配置宏，通过 recompileShaders() 选择 Shader 变体，再用 model.updateMaterial() 关联模型。曲线纹理的生成也在这个过程中

GPU的processor中有一个

typescript
this._tempParticle = new Particle(null);

在对应CPU端的处理中，这里有一个可以复用的粒子对象池，避免了反复销毁和创建新的粒子，GPU路径仍保存所有存活粒子的出生数据，但不逐帧保存计算后的当前位置和速度

曲线初始化 ​

updateMaterialParams 会进入initShaderUniform，代码如下：

typescript
    public initShaderUniform (mat: Material): void {
        const pass = mat.passes[0];

        this._uTimeHandle = pass.getHandle('u_timeDelta');
        this._uRotHandle = pass.getHandle('u_worldRot');
        this._uNodeRotHandle = pass.getHandle('nodeRotation');

        this.doUpdateScale(pass);
        pass.setUniform(pass.getHandle('frameTile_velLenScale'), this._unifrom_velLenScale);
        _tempVec4.x = _sample_num;
        _tempVec4.y = _sample_interval;
        pass.setUniform(pass.getHandle('u_sampleInfo'), _tempVec4);

        let enable = false;
        // force
        const forceModule = this._particleSystem?._forceOvertimeModule;
        enable = forceModule ? forceModule.enable : false;
        this._defines[FORCE_OVER_TIME_MODULE_ENABLE] = enable;
        if (enable) {
            const packed = packCurveRangeXYZ(this._forceTexture, this._forceData, _sample_num, forceModule!.x, forceModule!.y, forceModule!.z);
            this._forceTexture = packed.texture;
            this._forceData = packed.texdata;
            const handle = pass.getHandle('force_over_time_tex0');
            const binding = getBindingFromHandle(handle);
            pass.bindSampler(binding, this._forceTexture.getGFXSampler()!);
            pass.bindTexture(binding, this._forceTexture.getGFXTexture()!);
            const spaceHandle = pass.getHandle('u_force_space');
            pass.setUniform(spaceHandle, forceModule!.space);
            const modeHandle = pass.getHandle('u_force_mode');
            pass.setUniform(modeHandle, this._forceTexture.height);
        }

        // velocity
        const velocityModule = this._particleSystem?._velocityOvertimeModule;
        enable = velocityModule ? velocityModule.enable : false;
        this._defines[VELOCITY_OVER_TIME_MODULE_ENABLE] = enable;
        if (enable) {
            const packed = packCurveRangeXYZW(
                this._velocityTexture,
                this._velocityData,
                _sample_num,
                velocityModule!.x,
                velocityModule!.y,
                velocityModule!.z,
                velocityModule!.speedModifier,
            );
            this._velocityTexture = packed.texture;
            this._velocityData = packed.texdata;
            const handle = pass.getHandle('velocity_over_time_tex0');
            const binding = getBindingFromHandle(handle);
            pass.bindSampler(binding, this._velocityTexture.getGFXSampler()!);
            pass.bindTexture(binding, this._velocityTexture.getGFXTexture()!);
            const spaceHandle = pass.getHandle('u_velocity_space');
            pass.setUniform(spaceHandle, velocityModule!.space);
            const modeHandle = pass.getHandle('u_velocity_mode');
            pass.setUniform(modeHandle, this._velocityTexture.height);
        }

        // color module
        const colorModule = this._particleSystem?._colorOverLifetimeModule;
        enable = colorModule ? colorModule.enable : false;
        this._defines[COLOR_OVER_TIME_MODULE_ENABLE] = enable;
        if (enable) {
            const packed = packGradientRange(this._colorTexture, this._colorData, _sample_num, colorModule!.color);
            this._colorTexture = packed.texture;
            this._colorData = packed.texdata;
            const handle = pass.getHandle('color_over_time_tex0');
            const binding = getBindingFromHandle(handle);
            pass.bindSampler(binding, this._colorTexture.getGFXSampler()!);
            pass.bindTexture(binding, this._colorTexture.getGFXTexture()!);
            const modeHandle = pass.getHandle('u_color_mode');
            pass.setUniform(modeHandle, this._colorTexture.height);
        }

        // rotation module
        const roationModule = this._particleSystem?._rotationOvertimeModule;
        enable = roationModule ? roationModule.enable : false;
        this._defines[ROTATION_OVER_TIME_MODULE_ENABLE] = enable;
        if (enable) {
            let packed;
            if (roationModule!.separateAxes) {
                // eslint-disable-next-line max-len
                packed = packCurveRangeXYZ(this._rotationTexture, this._rotationData, _sample_num, roationModule!.x, roationModule!.y, roationModule!.z);
            } else {
                packed = packCurveRangeZ(this._rotationTexture, this._rotationData, _sample_num, roationModule!.z);
            }
            this._rotationTexture = packed.texture;
            this._rotationData = packed.texdata;
            if (this._rotationTexture) {
                const handle = pass.getHandle('rotation_over_time_tex0');
                const binding = getBindingFromHandle(handle);
                pass.bindSampler(binding, this._rotationTexture.getGFXSampler()!);
                pass.bindTexture(binding, this._rotationTexture.getGFXTexture()!);
                const modeHandle = pass.getHandle('u_rotation_mode');
                pass.setUniform(modeHandle, this._rotationTexture.height);
            }
        }

        // size module
        const sizeModule = this._particleSystem?._sizeOvertimeModule;
        enable = sizeModule ? sizeModule.enable : false;
        this._defines[SIZE_OVER_TIME_MODULE_ENABLE] = enable;
        if (enable) {
            let packed;
            if (sizeModule!.separateAxes) {
                packed = packCurveRangeXYZ(this._sizeTexture, this._sizeData, _sample_num, sizeModule!.x, sizeModule!.y, sizeModule!.z, true);
            } else {
                packed = packCurveRangeN(this._sizeTexture, this._sizeData, _sample_num, sizeModule!.size, true);
            }
            this._sizeTexture = packed.texture;
            this._sizeData = packed.texdata;
            if (this._sizeTexture) {
                const handle = pass.getHandle('size_over_time_tex0');
                const binding = getBindingFromHandle(handle);
                pass.bindSampler(binding, this._sizeTexture.getGFXSampler()!);
                pass.bindTexture(binding, this._sizeTexture.getGFXTexture()!);
                const modeHandle = pass.getHandle('u_size_mode');
                pass.setUniform(modeHandle, this._sizeTexture.height);
            }
        }

        // texture module
        const textureModule = this._particleSystem?._textureAnimationModule;
        enable = textureModule ? textureModule.enable : false;
        this._defines[TEXTURE_ANIMATION_MODULE_ENABLE] = enable;
        if (enable) {
            // eslint-disable-next-line max-len
            const packed = packCurveRangeXY(this._animTexture, this._animData, _sample_num, textureModule!.startFrame, textureModule!.frameOverTime, true);
            this._animTexture = packed.texture;
            this._animData = packed.texdata;
            const handle = pass.getHandle('texture_animation_tex0');
            const binding = getBindingFromHandle(handle);
            pass.bindSampler(binding, this._animTexture.getGFXSampler()!);
            pass.bindTexture(binding, this._animTexture.getGFXTexture()!);
            const infoHandle = pass.getHandle('u_anim_info');
            _tempVec4.x = this._animTexture.height;
            _tempVec4.y = textureModule!.numTilesX * textureModule!.numTilesY;
            _tempVec4.z = textureModule!.cycleCount;
            pass.setUniform(infoHandle, _tempVec4);
        }

        this._defines[USE_VK_SHADER] = deviceManager.gfxDevice.gfxAPI === API.VULKAN;
        this._defines[INSTANCE_PARTICLE] = this._useInstance;
    }

这里会把粒子属性相关的模块按固定的采样率采样成纹理，然后上传到GPU。 目前的采样率固定为32个采样点，直接在引擎中通过常量写死，没有暴露给编辑器用户调整

每帧更新 ​

粒子发射完毕后，会调用GPU Processor的updateParticles 整体的调用关系大致如下

text
GPU processor.updateParticles(dt)
    ├─ 编辑器非预览态：initShaderUniform()
    ├─ model.updateGPUParticles(...)
    ├─ updateShaderUniform(dt)
    └─ 根据存活数量设置 model.enabled

主要会处理两项工作

第一项：回收死亡粒子 相关处理的代码如下

typescript
// cocos/particle/models/particle-batch-model.ts:489
public updateGPUParticles (num: number, time: number, dt: number): number {
        if (!this._useInstance) {
            const pSize = this._vertAttrsFloatCount * this._vertCount;  // updateGPUParticlesIns的差异主要体现在这里，实例化的数据size大小不用乘上_vertCount
            let pBaseIndex = 0;
            let startTime = 0;
            let lifeTime = 0;
            let lastBaseIndex = 0;
            let interval = 0;
            for (let i = 0; i < num; ++i) {
                pBaseIndex = i * pSize;
                startTime = this._vdataF32![pBaseIndex + this._startTimeOffset];
                lifeTime = this._vdataF32![pBaseIndex + this._lifeTimeOffset];
                interval = time - startTime;
                if (lifeTime - interval < dt) {
                    lastBaseIndex = --num * pSize;
                    this._vdataF32!.copyWithin(pBaseIndex, lastBaseIndex, lastBaseIndex + pSize);
                    i--;
                }
            }

            return num;
        } else {
            return this.updateGPUParticlesIns(num, time, dt);
        }
    }

顶点计算 ​

这里就是目前GPU粒子实现的核心，GPU指的就是把一部分粒子的运动和外观属性放到了顶点着色器 核心的shader计算在editor\assets\chunks\builtin\internal\particle-vs-gpu.chunk

核心的计算流程如下： 1. 计算粒子年龄 核心代码如下

glsl
// editor/assets/chunks/builtin/internal/particle-vs-gpu.chunk:181
    float activeTime = u_timeDelta.x - a_position_starttime.w;
    float normalizedTime = clamp(activeTime / a_dir_life.w, 0.0, 1.0);

这里计算了粒子归一化的年龄
